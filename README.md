# rhabdo_death_krt
Prediction of Severe Outcomes in Rhabdomyolysis Using a Machine Learning Model: A Multicenter Validation Study

Data Files (see below):

df_e = data from eICU cohort

df_m = data from MIMIC IV cohort

df_c = combined data from both cohorts

The final calibrated model is accessible as a web-based calculator at https://huggingface.co/spaces/jomercier/rhabdo_death_krt. The datasets used in this study are publicly available and require completion of credentialing and data use agreements. In accordance with database governance policies, derived patient-level data are not redistributed, but consideration will be given on a case-by-case basis provided all requirements for access are met.
